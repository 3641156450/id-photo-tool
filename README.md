# id-photo-tool

证件照自动裁剪 · 换底色 · 多规格排版工具（纯前端，本地处理，不上传）

在线使用：https://3641156450.github.io/id-photo-tool/

## 功能

- **多规格裁剪**：一寸 / 小一寸 / 大一寸（护照）/ 二寸 / 小二寸 / 身份证 / 美签方照 / 日签方照，另可自定义 10–200mm 任意尺寸，统一按 300DPI 输出
- **一键换底色**：原图 / 白 / 蓝 / 红 / 透明（PNG）。采用「从四边向内漫溢」的 flood fill 抠图，带 1px 边缘羽化与去背景色污染处理，纯色背景（蓝幕 / 白墙 / 红布）效果最佳；识别失败会自动回退为原图并提示
- **自由构图**：拖动、滚轮 / 双指 / 滑块缩放、±15° 旋转、亮度与对比度微调、方向键逐像素微调
- **自动排版**：5 寸 / 6 寸 / A4 画布，行列数与空隙由程序求解最优方案（一寸 5 寸排 9 张、二寸 4 张）
- **清晰度提醒**：源图取景不足、放大倍率过高时给出提示
- **下载**：单张与排版图均可导出 PNG / JPG，文件名带规格、尺寸与时间戳

## 说明

- 纯前端，照片只在浏览器本地处理，不会上传到任何服务器
- 规格、画布、底色、容差等偏好记在本机 localStorage，下次打开自动恢复
- 超大图（超过 2500 万像素）会先降采样再处理，避免卡顿
- 规格与画布均为配置表驱动，新增只需往 `SPECS` / `SHEETS` 里加一条
