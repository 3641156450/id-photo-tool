# id-photo-tool

证件照裁剪 · 多尺寸排版工具（纯前端，本地处理，不上传）

在线使用：https://3641156450.github.io/id-photo-tool/

## 功能

- **按尺寸裁剪**：一寸（25×35mm）、二寸（35×53mm），另可自定义 10–200mm 任意尺寸，统一按 300DPI 输出
- **RAW 支持**：可直接打开佳能 CR2 等相机原始格式。浏览器内用 LibRaw（WASM）先做去黑电平 / 白平衡 / 反马赛克 / 转 sRGB，再进入裁剪——效果和 PS 打开 CR2 一致，不会发黑
- **整图旋转**：左转 90° / 右转 90° / 旋转 180°，另有 ±15° 微调
- **自由构图**：拖动、滚轮 / 双指 / 滑块缩放、亮度与对比度微调、方向键逐像素微调
- **自动排版**：5 寸 / 6 寸 / A4 画布，行列数与空隙由程序求解最优方案
- **清晰度提醒**：源图取景不足、放大倍率过高时给出提示
- **下载**：单张与排版图均可导出 JPG / PNG / TIFF / BMP（TIFF、BMP 为内置编码器，四种格式全部写入 300DPI 元数据，冲印软件打开即识别物理尺寸），文件名带尺寸、像素与时间戳

## 说明

- 纯前端，照片只在浏览器本地处理，不会上传到任何服务器
- 尺寸、画布、亮度、对比度偏好记在本机 localStorage，下次打开自动恢复
- 超大图（超过 2500 万像素）会先降采样再处理
- RAW 解码依赖同仓库内置的 `libraw/`（LibRaw WASM，本地加载，不依赖外部 CDN）；打开 CR2 需通过 https（线上地址）触发，离线 file:// 双击打开时 RAW 解码不可用
- 尺寸 / 画布均为配置表驱动，新增只需往 `SPECS` / `SHEETS` 里加一条
