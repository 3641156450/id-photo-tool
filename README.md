# id-photo-tool

证件照裁剪 · 手动换底色 · 多尺寸排版工具（纯前端，本地处理，不上传）

在线使用：https://3641156450.github.io/id-photo-tool/

## 功能

- **按尺寸裁剪**：25×35 / 22×32 / 33×48（护照）/ 35×53（二寸）/ 35×45 / 26×32 / 50.8×50.8（美签）/ 45×45（日签），另可自定义 10–200mm 任意尺寸，统一按 300DPI 输出
- **手动换底色（PS 式）**：不涂就不换，完全手动控制
  - **抠除笔**：涂抹要替换的背景（红色标记），软边自动羽化
  - **保留笔**：涂回被误抠的主体（头发、肩膀、衣服边缘），绿色标记强制保留原样
  - **擦标记**：擦掉已涂的红 / 绿，恢复未涂抹状态
  - **魔棒**：点一下背景，按容差选中相连的同色区域；同时把该点颜色设为背景取样色
  - **自动识别**：一键从四边向内漫溢标记背景，可作为起点再手动修补
  - **撤销**：支持多步撤销（一次落笔 = 一步）
  - 底色可选白 / 蓝 / 红 / **透明（PNG）**，边缘做去背景色处理，不会留下原底色彩边
- **整图旋转**：左转 90° / 右转 90° / 旋转 180°，蒙版与图层同步旋转；另有 ±15° 微调
- **自由构图**：拖动、滚轮 / 双指 / 滑块缩放、亮度与对比度微调、方向键逐像素微调
- **自动排版**：5 寸 / 6 寸 / A4 画布，行列数与空隙由程序求解最优方案（25×35mm 在 5 寸排 9 张、35×53mm 排 4 张）
- **清晰度提醒**：源图取景不足、放大倍率过高时给出提示
- **下载**：单张与排版图均可导出 PNG / JPG，文件名带尺寸、像素与时间戳

## 说明

- 纯前端，照片只在浏览器本地处理，不会上传到任何服务器
- 尺寸、画布、底色、笔刷、容差、当前工具等偏好记在本机 localStorage，下次打开自动恢复
- 超大图（超过 2500 万像素）会先降采样再处理；蒙版固定降采样到最长边 1600，涂抹时只增量重算笔刷覆盖的那一小块
- 实测 4000×3000（1200 万像素）涂抹约 10ms/帧
- 尺寸 / 画布 / 底色 / 工具均为配置表驱动，新增只需往 `SPECS` / `SHEETS` / `BGS` / `TOOLS` 里加一条
